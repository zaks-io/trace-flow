## Remaining plan defects (not blocking)

- **D1: the caller-side RPC flag isn't named.** `apps/agent-ingest/src/index.ts:41-48` calls `AgentIngestion` but its `withSentry` config has no `enableRpcTracePropagation`. Plan lines 167–171 frame the check from the callee side. Name the agent-ingest caller and the `eraseOrganization` path (`apps/agent-consumer/src/index.ts:197-202`, reached via `/internal/organization-erasure`) explicitly.
- **D2: Convex HTTP routes are missing from the trust matrix.** `packages/convex/httpRoutes/shared.ts:19` and `agentIngest.ts:15` read caller `traceparent`/`baggage` into log context. The trust classes in plan lines 94–95 don't list Convex HTTP actions as an ingress.
- **D3: the recovery Worker has production bindings.** `scripts/ingest-recovery/wrangler.jsonc:40-55` binds directly to the production consumers' `TraceRecovery` entrypoints. The plan's ban on hosted mutations covers this, but it should say outright that the audit inspects this Worker only and never runs or deploys it.
- **D4: deploy order isn't cited.** The reader-first rollout guidance doesn't point to the current consumer-first order in `.github/workflows/deploy.yml`. The audit should confirm that order before relying on it.
